# Python Pong – tanórai projekt

Egyszerű, kétjátékos Pong játék Pythonban, a beépített `turtle` modullal. Külső csomag telepítése nem szükséges.

## Futtatás

1. Töltsd le vagy klónozd a repozitóriumot.
2. Terminálban lépj a projekt könyvtárába.
3. Indítsd el:

```bash
python3 pong.py
```

A programhoz olyan Python-környezet kell, amelyben a Tk/Turtle grafikus felület működik.

## Irányítás

- Bal játékos: `W` – fel, `S` – le
- Jobb játékos: `↑` – fel, `↓` – le
- A játék automatikusan elindul. A labda elhagyásakor a másik játékos pontot kap.

## Tanulási célok

Változók, függvények, feltételek, ciklusok, billentyűzetkezelés, ütközésvizsgálat és egyszerű játéklogika gyakorlása.
